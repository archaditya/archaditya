## 🚀 Featured projects

### 1. [PushPostVault](https://www.pushpostvault.com) · live SaaS
Send large files and collect files from clients. Resumable chunked uploads with SHA-256 verification (client and server), an atomic Redis-backed state machine with optimistic locking on PostgreSQL, self-expiring and one-time download links, guest upload invites with enforced quotas, Cloudflare R2 storage, and subscription billing.
`Go` `Next.js` `PostgreSQL` `Redis` `Cloudflare R2` `Docker` `Nginx`
[🌐 Live](https://www.pushpostvault.com) · [📦 Source](https://github.com/archaditya/bytevault)

### 2. [AI PR Review Bot](https://pr-review-bot.archadi.dev) · live platform
Multi-tenant GitHub App that reviews pull requests using a Neo4j code-dependency graph, so findings are grounded in real cross-file impact. Supports inline `@mention` follow-up chat, encrypted bring-your-own-key (AES-256-GCM), a tenant admin dashboard, and turns merged PRs into LinkedIn / X post drafts. Three decoupled services (webhook, Node/Express API, Python/FastAPI AI engine).
`Node.js` `Express` `FastAPI` `Neo4j` `PostgreSQL` `Inngest` `Next.js`
[🌐 Live](https://pr-review-bot.archadi.dev) · [📦 Source](https://github.com/archaditya/github-pr-review-bot)

### 3. [ArchadiLM](https://archadilm.archadi.dev) · multi-tenant RAG workspace
A NotebookLM-style assistant that indexes PDFs, web pages, video transcripts, and source archives, then answers with grounded, citation-backed responses. Step-back query expansion with HyDE, Qdrant HNSW search, Reciprocal Rank Fusion, cross-encoder reranking, async Redis Streams ingestion workers, and SSE token streaming.
`Go` `FastAPI` `Qdrant` `PostgreSQL` `Redis Streams` `Cloudflare R2`
[🌐 Live](https://archadilm.archadi.dev) · [📦 Source](https://github.com/archaditya/course-bot)

### 4. [archadi-agent](https://www.npmjs.com/package/archadi-agent) · TypeScript Agent SDK (on npm)
Fluent builder API with a native function-calling runner, multi-agent handoffs, guardrails, structured output, streaming events and tracing, and model fallback. Includes a CLI (`archadi chat`) with demo agents and a REPL, plus session and long-term memory via mem0ai.
`TypeScript` `Node.js` `npm`

### 5. [AI Engineering Playground](https://ai-playground.archadi.dev) · live demo
A Next.js 15 workspace with one page per GenAI exercise: persona chat, multi-LLM voting, RAG chat, tool calling, memory agents, and MCP integrations.
`Next.js 15` `TypeScript` `OpenAI SDK` `Anthropic SDK` `LangChain`

### 6. Verkin · in development
A networking platform where AI technical conversations double as a way to find other engineers discussing related problems, matched by topic semantics.
`Next.js` `Node.js` `PostgreSQL` `Vector Search`
